# Design studies

These notes examine four Runtime decisions at the c17c boundary. They start from a concrete Forge problem, describe the implemented mechanism, compare a small set of current coding-agent designs, and state the trade-off.

They are not a market survey or a feature plan. External systems change quickly; links point to their official documentation as the source of each behavioral claim.
